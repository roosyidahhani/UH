Integrasi Cloud Google Spreadsheet

Konfigurasikan agar setiap kali siswa mengklik "Kirim", nilainya langsung muncul di baris baru file Google Spreadsheet Anda secara otomatis!

Langkah 1: Pasang Google Apps Script

  1. Buat sebuah file Google Spreadsheet baru.
  2. Buka menu Ekstensi / Extensions di bagian atas menu bar, lalu pilih Apps Script.
  3. Hapus semua kode bawaan yang ada di editor tersebut.
  4. Salin dan tempelkan (copy-paste) seluruh kode script berikut ini ke dalam editor tersebut:
function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    
    // Tambah header jika sheet masih kosong
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(["Tanggal Pengiriman", "Nama Siswa", "Mata Pelajaran", "Skor", "Benar", "Salah", "Total Soal", "Detail Jawaban"]);
      sheet.getRange(1, 1, 1, 8).setFontWeight("bold").setBackground("#e2e8f0");
    }
    
    var formattedDate = Utilities.formatDate(new Date(), Session.getScriptTimeZone(), "yyyy-MM-dd HH:mm:ss");
    var detailString = JSON.stringify(data.answers || {});
    
    sheet.appendRow([
      formattedDate,
      data.studentName,
      data.quizTitle,
      data.score,
      data.correct,
      data.wrong,
      data.totalQuestions,
      detailString
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({ "status": "success", "message": "Nilai berhasil disimpan" }))
      .setMimeType(ContentService.MimeType.JSON);
      
  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({ "status": "error", "message": error.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

Langkah 2: Deploy & Publikasikan Script

  1. Klik tombol Deploy (Terapkan) -> New deployment (Penerapan baru).
  2. Klik ikon gerigi di sebelah "Select type", pilih Web app (Aplikasi web).
  3. Atur opsinya:
    • Execute as: Me (email Anda sendiri)
    • Who has access: Anyone (Siapa saja) (Pilihan krusial agar web diijinkan memasukkan baris baru).
  4. Klik Deploy, lalu ketuk Izinkan Akses / Grant Access dan setujui langkah keamanan sampai selesai.
  5. Salin alamat tautan **URL Aplikasi Web** yang tampil di akhir layar.
